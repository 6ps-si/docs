## Supported formats

Mesh formats: glTF, GLB, OBJ, STL, DAE, 3DS. Gaussian splat formats: .sog, .splat, .spz,
.ply.

## Uploading

The upload flow and where the file goes in your library.

## Automatic optimization

Uploads are optimized so they load on lower-powered devices. Keep this generic.

## Converting an FBX file

FBX is not uploaded directly. The editor offers to convert it, and there is a standalone
converter at studio.6ps.si/tools/fbx-converter.

## Using the standalone converter

Free, no account, and the file stays in your browser. This tool is also useful on its own,
outside the editor.
