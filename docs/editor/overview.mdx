## What the editor does

Configure how a model looks and behaves for viewers, then publish it. Keep to workflow time
claims rather than final-render claims.

## The layout

Left sidebar for the object tree and panel switching, the viewer in the middle, contextual
settings on the right.

## On a phone

The same panels appear in a bottom sheet. The editor is designed to work fully on mobile.

## Trying it without an account

The editor is browsable signed out. Signing in is required to publish.

## Help tips

The small question-mark icons next to settings explain each control in place.
