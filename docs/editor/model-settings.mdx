## Choose a model

The **Objects** panel lists every model in your scene with its file type and name. Click one to select it. The **Model** panel stays greyed out until a model is selected.

- Click the **+** button to add another model. See [Uploading models](/docs/editor/uploading-models).
- Hover over a model and open the menu to **Delete** it.

<Note>
  When you reopen a project that is already published, the **+** button and **Delete** are unavailable. You can still change the settings of the models it contains.
</Note>

## Move, rotate, and scale

You can adjust a model in two ways: directly in the viewer with the gizmo, or by typing values.

### The gizmo

Under **Gizmo**, choose **Move**, **Rotate**, or **Scale** to show the matching handles on the selected model, then drag them in the viewer. Click the active button again to hide the handles.

### Typed values

Three rows of X, Y, and Z fields give you exact control:

| Field | What it sets |
| --- | --- |
| **Scale** | The model's size along each axis. |
| **Position** | Where the model sits in the scene. |
| **Rotation** | The model's rotation around each axis, in degrees. |

Type a number, use the arrows, or scroll the mouse wheel over a field to change it in steps. For **Scale**, the padlock icon keeps all three axes together so the model grows and shrinks evenly. Click the padlock to unlock the axes and scale them separately.

When you add the first model to a scene, Studio suggests a scale so the model fills the viewer.

## Mirroring

**Mirror Axes** flips the model across the X, Y, or Z axis. Use it when a model arrives back to front or upside down. Click an axis to toggle it.

## Materials

The **Materials** drawer, in yellow at the bottom of the panel, adjusts how a model looks. Click it to open it.

| Control | What it does |
| --- | --- |
| **Brightness** | Above 1 brightens the colors, below 1 darkens them. |
| **Contrast** | 1 is neutral. Higher values add contrast and lower values flatten it. |
| **Saturation** | 0 is greyscale, 1 is the original, and above 1 is more vivid. |
| **Tint Color** | The color blended into the model. |
| **Tint Strength** | How much of the tint to blend in. 0 is none and 1 is fully tinted. |

Click **Reset to defaults** at the bottom of the drawer to undo every change in it.

<Info>
  The Materials controls apply to Gaussian splat models (`.ply`, `.sog`, `.splat`, and `.spz` files).
</Info>

### Dot Mode

**Dot Mode** replaces the soft edges of a splat with hard-edged circles for a pointillist look. When it is on, **Dot Radius** sets the size of each dot.

### Fog

**Fog** fades a splat to a solid color as it approaches the far edge of the view. When **Fog** is on, three controls appear:

- **Fog Color** is the color the model fades to.
- **Fog Near** is the depth where the fade begins.
- **Fog Far** is the depth where the model is fully faded.

Both depth sliders sit close to the far edge of the view, so make small adjustments.

## Combined Sort

**Combined Sort** applies when your scene holds several splat models that overlap. It merges them so they blend in the correct order. While it is on, the per-model Materials settings are switched off, so use it only when overlapping models look wrong without it.
