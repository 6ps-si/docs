Select a model in the **Objects** panel to open its settings in the **Model** panel on the right. Here you place the model in the scene and, for Gaussian splat models, adjust how it looks. To add or delete models, use the **+** button and the menu in **Objects**.

## Move, rotate, and scale

Under **Gizmo**, choose **Move**, **Rotate**, or **Scale** to show handles on the model, then drag them in the viewer. For exact values, use the **Scale**, **Position**, and **Rotation** fields. Rotation is in degrees.

The padlock next to **Scale** keeps all three axes together so the model scales evenly. Unlock it to scale the axes separately.

When you add the first model to a scene, Studio suggests a scale so the model fills the viewer.

**Mirror Axes** flips the model across the X, Y, or Z axis, which helps when a model arrives back to front or upside down.

## Materials

<Info>
  The Materials controls apply to Gaussian splat models (`.ply`, `.sog`, `.splat`, and `.spz` files).
</Info>

The **Materials** drawer at the bottom of the panel adjusts how a splat looks.

| Control | What it does |
| --- | --- |
| **Brightness** | Above 1 brightens the colors, below 1 darkens them. |
| **Contrast** | 1 is neutral. Higher values add contrast and lower values flatten it. |
| **Saturation** | 0 is greyscale, 1 is the original, and above 1 is more vivid. |
| **Tint Color** | The color blended into the model. |
| **Tint Strength** | How much of the tint to blend in. 0 is none and 1 is fully tinted. |

**Dot Mode** replaces the soft edges of a splat with hard-edged circles for a pointillist look. **Dot Radius** sets the size of each dot.

**Fog** fades a splat to **Fog Color** with distance. The fade starts at **Fog Near** and is complete at **Fog Far**. Both sliders sit close to the far edge of the view, so make small adjustments.

## Combined Sort

**Combined Sort** applies when your scene holds several splat models that overlap. It merges them so they blend in the correct order. While it is on, the per-model Materials settings are switched off, so use it only when overlapping models look wrong without it.
