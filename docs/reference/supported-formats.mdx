This page lists the file types each part of Studio accepts.

## 3D mesh formats

The 3D Editor accepts these mesh model formats.

| Format | Extensions | Notes |
| --- | --- | --- |
| glTF | `.gltf` | Select the companion files together with the model: the `.bin` data file and any texture images it points to. If one is missing, the editor lists what it could not find. |
| GLB | `.glb` | A single file that holds everything. The simplest choice. |
| OBJ | `.obj` | |
| STL | `.stl` | |
| Collada | `.dae` | |
| 3DS | `.3ds` | |

Texture images can be added alongside a model as `.jpg`, `.jpeg`, `.png`, `.webp`, or `.ktx2` files.

## Gaussian splat formats

The 3D Editor also accepts 3D Gaussian Splatting files:

| Format | Extension |
| --- | --- |
| SOG | `.sog` |
| Splat | `.splat` |
| SPZ | `.spz` |
| PLY | `.ply` |

The Materials settings for a model, such as tint, dot mode, and fog, apply to these formats. See [Model settings](/docs/editor/model-settings).

## FBX

Studio cannot load FBX files directly. Convert an FBX file to GLB first. The editor offers to convert it when you add one, and there is a free [FBX to GLB converter](https://studio.6ps.si/tools/fbx-converter/) that works in your browser. See [Uploading models](/docs/editor/uploading-models#converting-an-fbx-file).

## Environment images

The **Select HDRI** dialog in the 3D Editor accepts these files:

| Type | Extensions |
| --- | --- |
| 360° Image | `.jpg`, `.jpeg`, `.png` |
| HDR Environment | `.hdr`, `.exr` |

See [Scene and environment](/docs/editor/scene-and-environment).

## Walkthrough images

The Virtual Walkthrough editor accepts JPG, PNG, and WebP images for both **360° Image** and **Flat Image** rooms.

A 360° room needs an equirectangular photo. When you publish, Studio scales a 360° photo down to at most 4096 pixels on its longest side, and about 10 MB, before it prepares the room. You do not need to resize photos yourself. See [Capturing photos](/docs/walkthrough/capturing-photos).

## AI image uploads

**AI Virtual Staging** accepts JPG, PNG, and WebP images up to 30 MB. Before an image is sent to the AI, Studio scales it down to at most 4096 pixels on its longest side and compresses it. See [AI Virtual Staging](/docs/ai-staging/overview).

The **Reference image** in **AI Render** in the 3D Editor accepts JPEG, PNG, and WebP files. See [AI render](/docs/editor/ai-render#reference-images).

## Size limits

| Where | Limit |
| --- | --- |
| AI Virtual Staging upload | 30 MB per image |
| Walkthrough 360° photos | Scaled to 4096 pixels on the longest side and about 10 MB when publishing |
| Team logo | An image file, chosen in **Choose a team logo** |

The **Size** card in a model's statistics compares your published model with a mobile-friendly size, so you can see whether it is light enough for phones. See [Engagement and analytics](/docs/sharing/engagement-and-analytics#what-is-measured).
