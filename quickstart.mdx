## Before you start

Prerequisites: a 6PS account, and either a 3D model file or a set of 360 room photos.

## Create a project

Use Create in the top bar, then choose a 3D model or a walkthrough. Note that the Create
modal is the entry point for both.

## Set it up

Short version of each path, with links to the full tool sections rather than repeating the
detail.

## Publish

Name, description, visibility, then publish.

## Share it

Copy the link or the embed snippet. Link to the sharing section.
