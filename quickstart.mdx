This guide takes you from an empty library to a published project with a link you can share. Pick the path that matches what you have.

<Frame><img src="/images/get-started/quickstart-create.webp" alt="The Choose Project Type dialog with the 3D Editor, Virtual Walkthrough, and AI Virtual Staging options" /></Frame>

## Before you start

You need:

- A 6PS Studio account. You can try the editors without one, but you need to sign in to publish.
- Either a 3D model file, or a set of 360° room photos.

## Create a project

Click **Create** in the top bar. The **Choose Project Type** dialog opens:

- **3D Editor** for a 3D model.
- **Virtual Walkthrough** for a tour built from room photos.
- **AI Virtual Staging** for editing a single image with AI.

Choose one and click **Continue**. You can also start from the plus card in **My Scenes** in your [library](/docs/library/overview).

## Set it up

<Tabs>
  <Tab title="3D model">
    1. Drag your model file onto the editor, or click to browse. See [Uploading models](/docs/editor/uploading-models) for the formats you can use.
    2. Frame the model in the viewer, then click **+** in **Positions** to save that view. See [Camera positions](/docs/editor/camera-positions).
    3. Adjust the model, background, and lighting if you like. See [Model settings](/docs/editor/model-settings) and [Scene and environment](/docs/editor/scene-and-environment).
  </Tab>
  <Tab title="Walkthrough">
    1. Drag a 360° photo onto the editor, and choose **360° Image** when asked what type of image it is. See [Capturing photos](/docs/walkthrough/capturing-photos).
    2. Use **Add room** in the **Scenes** list to add the rest of your rooms.
    3. Connect the rooms with **Room Transition** buttons. See [Building a tour](/docs/walkthrough/building-a-tour).
  </Tab>
</Tabs>

## Publish

<Steps>
  <Step title="Name it">
    In **Scene info**, enter a **Name** and, if you like, a **Description**. Publishing needs a name.
  </Step>
  <Step title="Choose who can see it">
    Pick **Public**, **Unlisted**, or **Private** in the **Visibility** selector. See [Visibility and ownership](/docs/library/visibility-and-ownership).
  </Step>
  <Step title="Publish">
    Click **Publish** and confirm. Studio prepares and uploads your project while a progress bar runs. See [Publishing a model](/docs/editor/publishing) or [Publishing a walkthrough](/docs/walkthrough/publishing).
  </Step>
</Steps>

## Share it

When publishing finishes, the share dialog shows a **Share Link** and a QR code. Copy the link to send it, or embed the project in your own website. See [Share links and embedding](/docs/sharing/links-and-embedding).

To see how your project is doing afterward, read [Engagement and analytics](/docs/sharing/engagement-and-analytics).
